# 画面設計

## 画面一覧

| ID | 画面 | 役割 |
|---|---|---|
| S01 | ホーム | 最近の日記などを表示 |
| S02 | 日記一覧 | 記述した日記の一覧を表示 |
| S03 | 日記作成 | 日記を実際に作成 | 
| S04 | 日記詳細 | 日記の詳細を表示 |
| S05 | 日記編集 | 作成した日記を編集する|

## S01 ホーム

### 役割
アプリを開いた際に最初に表示される画面。最近の日記や現在の記録状況を確認し、日記作成や過去の日記の確認へ移動できる。

### 表示項目
- アプリ名
- 今日の日付
- 「日記を書く」ボタン
- 日記一覧へのリンク
- 「最近の日記を確認する」ボタン
- 今月の平均満足度

### 操作
- 「日記を書く」ボタンでS03に遷移
- 日記一覧のリンクでS02に遷移
- 「最近の日記を確認する」ボタンでS04に遷移

## S02 日記一覧

### 役割
今まで作成した日記を一度に表示し、いつにどのような日記を書いたのかを確認できる

### 表示項目
- 日付
- 日記のタイトル
- 日記にある満足度
- 「ホームに戻る」ボタン

### 操作
- 日記をタップするとS04に遷移
- 「ホームに戻る」ボタンをおすとS01に遷移
