# 書けば書くほど充実する日記アプリ Loyality Diary
このアプリはただ日記を記録していくだけではない。
日記を記録していけばいくほど、昔からの成長を確認できる。
1ヶ月の満足度を知ることができる。
昔たてた目標がいつ達成できたかを確認することができる。

ただ日記をつけるだけで、過去の自分からどれほど成長したかを明確にしながらモチベーションを保ってくれるアプリ。

## 備わっている機能

### 最低限備わっているべき機能(MVP)
- 日記を書くことができる
- 日記に画像を貼ることができる
- 日記にタグをつけることができる
- 過去の日記を確認することができる
- その日の満足度を記録することができる
- 記録した日記情報を編集・削除することができる

### 最終的に備えたい機能
- AIによる日記分析・ようやく出力ができる
